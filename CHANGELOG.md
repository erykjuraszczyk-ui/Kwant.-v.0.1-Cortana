# Changelog

## 1.0.0
- Połączono pamięć trwałą, model świata, fuzję, predykcję, regułowy silnik decyzyjny i warstwę dialogową.
- Dodano `GET /system/status`.
- Rozszerzono panel Cortany o status systemu, opcjonalne dyktowanie przez Web Speech API i syntezę mowy przez przeglądarkę.
- Mikrofon włącza się wyłącznie po kliknięciu; rozpoznany tekst wymaga oddzielnego wysłania.
- Dodano dokumentację ograniczeń i implikacji prywatności głosu.
- Utrzymano lokalny tryb reguł jako domyślny i pozostawiono opcjonalne adaptery modelu językowego.
